# Commit history

This project was built as a series of atomic commits: one logical change per
commit, implementation and its tests as separate commits, config committed
independently from code. The full history in `git log` is the build log —
reading it top to bottom tells the same story as the README, at the level of
individual files.

Format: `<type>(<file>): <what and why>`, where type is one of `feat`, `fix`,
`refactor`, `docs`, `chore`.
